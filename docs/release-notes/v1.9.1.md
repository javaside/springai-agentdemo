# springai-agentdemo v1.9.1

在 [v1.9.0](v1.9.0.md) 基础上的**修订版**（patch）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

本版主题是 **`/skill` 大量技能选择器稳定性修复**：选择器不再一次渲染全部技能，而是使用最多 10 项的跟随窗口，避免面板超过终端高度后 InlineDisplay 与终端滚动反复重排。所有技能仍可用方向键遍历并按 Enter 挂载。

**下载物仍是两个自包含运行包（解压即用，无需构建）：**

- `springai-code-tui-1.9.1-dist.tar.gz`（macOS / Linux 首选）
- `springai-code-tui-1.9.1-dist.zip`（Windows 首选）

两者内容一致：启动脚本（`bin/`）+ 主 jar + 全部运行期依赖（`lib/`）+ 配置示例 + 使用指南 + `LICENSE`/`NOTICE`/`README`。运行时界面版本标识为 **`v1.9.1`**。

> 完整功能全景与安全声明见 [v1.3.0 发布说明](v1.3.0.md) 与 [v1.0.0 发布说明](v1.0.0.md)；本文只列出相对 v1.9.0 的变化。

## 修复：大量技能时 `/skill` 不再持续闪动

当用户安装了很多技能并通过 `/skill` 打开选择器时，旧实现会把全部技能一次性放进 InlineDisplay。面板高度一旦超过终端可用高度，运行器会按 `preferredSize` 扩缩显示区，而终端同时发生滚动和重排；两者互相追赶，最终表现为界面持续闪动、上下晃动，方向键和 Enter 也难以稳定操作。

本版将技能选择器改成**固定高度的跟随窗口**：

- 最多同时显示 10 个技能，面板高度保持稳定；
- 高亮项移动到当前窗口之外时，窗口自动跟随；
- 底部显示 `显示 11-20 / 共 40 个技能` 这样的范围提示；
- 技能清单没有被截断，所有项目仍可通过方向键遍历并按 Enter 挂载；
- 少于或等于 10 个技能时维持原来的完整展示，不增加范围提示。

该修复只影响选择器渲染，不改变技能发现、热加载、手动注入和模型自动调用行为。

## 文档与发布包入口整理

v1.9.0 之后，`springai-code-tui/README.md` 的快速开始重新聚焦到可下载运行包：

- 下载入口统一指向 GitHub Releases；
- 明确 macOS/Linux 使用 tar.gz、Windows 使用 zip；
- 解压后的 `bin/config.env` 配置与 `bin/code-tui` / `bin/code-tui.cmd` 启动步骤更直接；
- 源码运行与发布包运行分开说明；
- 启动脚本和文档统一要求 **JDK 17+**。

这些是文档与提示整理，不改变归档结构和运行时依赖。
