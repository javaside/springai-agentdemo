# v1.29.0 — headless 非交互模式（-p）与生命周期钩子（hooks）

在 [v1.28.0](v1.28.0.md) 基础上的**功能版**（minor）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

发布日期：2026-10-27。

## 新增：headless 非交互模式（-p）

此前 code-tui 只有交互式 TUI 一种用法，没法进脚本/CI 流水线。本版对标 Codex `codex exec` 与
Claude Code `-p` 模式，补齐一次性非交互执行：

- **`code-tui -p "提示词"`**：非交互执行一次——完整走装配（AGENTS.md/MCP/技能同 TUI），agent
  跑完后回复打到 stdout、进程退出。`-p` 不带值时从 **stdin** 读提示词（管道友好）。
- **退出码**：`0` 成功；`1` 回合失败（模型/工具链错误原样退出，stderr 带原因）；`2` 用法错误
  （参数组合非法等）——脚本可据码分支。
- **`--output-last-message <file>`**：把最后一条助手消息原文写入指定文件（文件不存在则跳过
  该功能，不报错），供下游工具直接取用；`-p` 与交互模式均可用。
- **两个环境变量**：`CODETUI_HEADLESS_MCP_WAIT_SECONDS`（MCP server 就绪等待，默认 10）与
  `CODETUI_HEADLESS_MAX_SECONDS`（总硬顶，默认 3600）——无人值守时防挂死。
- **fail-closed 模态处置**：权限询问等需要人回答的模态在 headless 下不挂等，直接按拒绝处理
  并在 stderr 说明——非交互环境宁可失败、绝不僵死。
- 与 `-c` / `--resume <id>` 组合可链式续会话：headless 跑完会话照常落盘，下一次 `--resume`
  接着上文继续（真机冒烟覆盖一次性回复/落盘/链式三条路径）。

审查后三处加固：stdin 读入不提前 close（防上游管道截断）、空白提示词直接退出码 2、`-c` 找不到
会话时显式提示而非静默新开。设计文档见
[`../superpowers/specs/2026-10-25-headless-mode-design.md`](../superpowers/specs/2026-10-25-headless-mode-design.md)。

## 新增：生命周期钩子（hooks）

对标 Claude Code hooks：在固定生命周期时点自动执行你自己配置的 shell 命令，四个事件：

| 事件 | 触发时机 | 行为 |
| --- | --- | --- |
| `PreToolUse` | 工具执行前 | 钩子 `exit 2` = **拦截**本次调用（stderr 截 2000 字作为理由返回给模型）；`exit 0` 放行；其它非零/超时不拦截 |
| `PostToolUse` | 工具执行成功后 | stdout（截 2000 字）以 `[PostToolUse 钩子输出]` 段追加进工具结果，UI 与模型都可见 |
| `Stop` | 回合结束 | 通知型，异步执行不拖回合收尾 |
| `SessionStart` | 启动装配时 | 通知型，同步执行（建议配短 timeout） |

- **配置两层**：`~/.codetui/hooks.json`（用户层）与 `<工作目录>/.codetui/hooks.json`（项目层），
  同事件合并全部执行；`matcher` 按工具名正则过滤（仅 Pre/Post），`timeout` 默认 60 秒、钳在
  [1,120]（上界刻意远小于流式空闲超时，防钩子拖死回合）。钩子进程经 `sh -c` 执行、工作目录为
  项目根，stdin 收到一行 JSON（含 `toolName`/`toolInput`/`root` 等，超长截 8KB）。
- **项目层信任模型**：hooks 能执行任意命令，而项目层配置随仓库分发——clone 别人仓库不该自动
  执行其中的命令。项目层钩子默认**不执行**，`/hooks` 面板查看全部钩子（未信任条目带 ⚠ 标记）、
  按 `t` 信任：把当前文件内容 sha256 记入 `~/.codetui/hooks-trust.json`（用户空间、按项目根
  绝对路径），**即时生效**；文件内容再改则失配，下次启动回到未信任。用户层无需信任；
  `--dangerously-skip-permissions` 不旁路钩子信任。
- 已知边界（声明接受）：无热重载（改 hooks.json 需重启）；MCP 工具不触发钩子（权限层已对未知
  工具兜底）；hash 信任防「信任后被改」，防不住 agent 自写信任文件（本工具无沙箱是既有立场）。

新命令：`/hooks`。格式、stdin payload 字段表与退出码语义详见
[reference.md](../../springai-code-tui/docs/guide/reference.md#生命周期钩子hooks)。设计文档见
[`../superpowers/specs/2026-10-25-hooks-design.md`](../superpowers/specs/2026-10-25-hooks-design.md)。

## 用户可见的变化

- 新启动参数：`-p [提示词]`（headless 非交互）、`--output-last-message <file>`。
- 新命令：`/hooks`（钩子面板：列表/未信任标记/`t` 信任）。
- 新配置文件：`~/.codetui/hooks.json`、`<项目>/.codetui/hooks.json`、`~/.codetui/hooks-trust.json`。
- 新环境变量：`CODETUI_HEADLESS_MCP_WAIT_SECONDS`、`CODETUI_HEADLESS_MAX_SECONDS`。
- 不用 `-p`、不配 hooks.json 时行为与 v1.28.0 完全一致；无新增计费项。
