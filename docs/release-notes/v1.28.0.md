# v1.28.0 — 会话管理增强（/resume /fork --resume）与 /init /review /diff 三命令

在 [v1.27.0](v1.27.0.md) 基础上的**功能版**（minor）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

发布日期：2026-10-25。

## 新增：/resume 会话面板、/fork 分叉与 --resume 启动参数

此前只有 `-c`（恢复最近一次会话）：选不了、分叉不了、清理不了。本版对标 Codex `/resume /fork`
与 Gemini `/chat list|resume`，补齐运行期会话管理：

- **`/resume` 面板**：列出 `.codetui/sessions/` 全部会话（时间 + 首条用户消息摘要），Enter 恢复、
  `f` 分叉选中项、`d` 删除（两段式确认，对齐 `/permissions` 先例）、Esc 关闭；Enter 前忙碌复检，
  agent 干活中不会切走会话。列表只扫文件名 + mtime，**面板秒开**；摘要由后台线程流式补齐
  （单文件读到首条用户消息即停——192 个会话、最大 773KB 的实测规模不卡按键线程），摘要剥离
  注入文本（技能挂载/文件引用包裹）后展示，与当时画面所见一致。
- **`/fork`**：分叉**当前**会话到新会话 id 并切过去，原会话文件一字不动；与面板 `f` 键共用同一实现。
- **`--resume <id>` 启动参数**：按会话 id 精确或唯一前缀匹配直接恢复指定会话；与 `-c` 互斥（同给报错）。
- 运行期切换（恢复/分叉）复用 `/clear` 的完整切换序列：杀后台任务、清 interjection/goal/todo 提醒等
  会话级状态、清屏防 resize 重放复活旧会话画面。

设计文档见 [`../superpowers/specs/2026-10-23-session-management-design.md`](../superpowers/specs/2026-10-23-session-management-design.md)。

## 新增：/init、/review、/diff 三命令

对标 Codex 与 Claude Code 同名命令：

- **`/init`**：让 agent 分析项目并生成/改进项目级 `AGENTS.md`（不碰用户级 `~/.codetui/AGENTS.md`）；
  已存在则保留既有事实、**改进而非整篇重写**；只写「从代码推不出来的事实」；写完明说
  **重启 code-tui 后生效**（AGENTS.md 是装配期一次性烘焙进系统提示的）。
- **`/review`**：让 agent 只读审查工作树改动——先 `git diff HEAD` + `git status`（含未跟踪）看全貌，
  按正确性/安全/测试/可维护性四维度找问题、按严重度排序输出；**只读审查，除非用户明确要求否则
  不动手修**。非 git 仓库时 UI 预检一行拒绝，不白烧一次模型调用。
- **`/diff`**：**不经模型**，把 `git diff HEAD`（含未跟踪文件列表，只列名 + 字节数）逐字打进
  scrollback。git 跑在 daemon 线程（大仓库不冻 UI）；输出走专用单色通道，`+/-/#` 等标记不经
  markdown 渲染、原样逐字下沉；分批输出、批间同校验代际，面板已关/已切会话即弃；同一时刻
  至多一个 `/diff` 在跑（单飞）。

设计文档见 [`../superpowers/specs/2026-10-23-init-review-diff-design.md`](../superpowers/specs/2026-10-23-init-review-diff-design.md)。

## 修复：/resume 面板两个实机问题

- **删除会话后列表摘要丢失/已删行复活**：摘要后台线程与主线程对会话列表的写交错——引入
  `sessionEpoch` 代际计数（打开/Esc/切换/删除各 +1，后台线程回写前校验代际，过期即弃），
  删除后由新代线程重算摘要。
- **Esc 关闭面板后输入框消失**：会话列表无封顶，190+ 个会话把终端高度撑爆，Esc 收缩时
  InlineDisplay 记账错位（同 `/model` 面板历史事故同构）——`SESSIONS_PICKER_CAP=10` 固定窗口收口。
  教训已立规：**新增行内选择器面板必须带封顶**（skill/model/sessions 三次事故）。

## 用户可见的变化

- 新命令：`/resume` `/fork` `/init` `/review` `/diff`（补全菜单按前缀自动适配，与既有命令无前缀冲突）。
- 新启动参数：`--resume <id>`（前缀匹配，与 `-c` 互斥）。
- 会话目录里攒下的历史会话从此可选、可分叉、可清理；工作树改动可以一屏逐字过目（`/diff`）、
  让 agent 生成或改进项目指令（`/init`）、做一轮只读审查（`/review`）。
- 未用到新命令时行为无任何变化；无新增环境变量、无新增计费项。
