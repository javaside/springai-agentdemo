# springai-agentdemo v1.19.1

在 [v1.19.0](v1.19.0.md) 基础上的**修订版**（patch）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

本版一件事：**Anthropic 新模型 Claude Fable 5.1 接入**。2026 年 8 月发布的 `claude-fable-5-1` 是 Anthropic 当前最强旗舰（面向高难推理与长时程 agentic 任务），本版将其纳入内置清单，并同步上下文窗口与 thinking 能力判定。

**下载物为两个自包含运行包（解压即用，无需构建）：**

- `springai-code-tui-1.19.1-dist.tar.gz`（macOS / Linux 首选）
- `springai-code-tui-1.19.1-dist.zip`（Windows 首选）

两者内容一致：启动脚本（`bin/`）+ 主 jar + 全部运行期依赖（`lib/`）+ 配置示例 + 使用指南 + `LICENSE`/`NOTICE`/`README`。运行时界面版本标识为 **`v1.19.1`**。

> 完整功能全景与安全声明见 [v1.3.0 发布说明](v1.3.0.md) 与 [v1.0.0 发布说明](v1.0.0.md)；本文只列出相对 v1.19.0 的变化。

## 功能：Claude Fable 5.1 接入

### `claude-fable-5-1` 入内置清单（最强旗舰）

`claude-fable-5-1`（1M 上下文 / 128K 输出，定价 $10 / $50 per MTok）加入 Anthropic 内置清单，描述标注「最强旗舰 · 长时程 agent」，`/model` 可直接切换。

**默认模型仍是 `claude-opus-5` 不变**——官方模型总览建议多数负载从 Opus 5 起步；加模型不悄悄改默认，已存偏好与新项目都不受影响。

### 旧旗舰 `claude-fable-5` 的处置

官方在售清单已看不到 `claude-fable-5`。沿用 opus-4-8 转上代的先例，它**保留在清单末尾**（描述改「上代旗舰」），老配置不失效；官方下线该端点后可经 `ANTHROPIC_MODELS` 自定义移除。

清单现调整为：`claude-opus-5`（默认）/ `claude-fable-5-1` / `claude-sonnet-5` / `claude-haiku-4-5` / `claude-opus-4-8`（上代 opus）/ `claude-fable-5`（上代旗舰）。

### thinking 能力：fable 前缀匹配

`claude-fable-5-1` 与 fable-5 一样，thinking 为 **Adaptive always-on，不可禁用**；effort 档位 `low` / `medium` / `high` / `max`。判定逻辑从精确匹配 `claude-fable-5` 改为 **`claude-fable-` 前缀匹配**——后续 5-x 版本发布时不再漏判。

### 内置上下文窗口

`ModelContextWindows` 新增 `anthropic:claude-fable-5-1` → **1M**。压缩器不会把新旗舰按保守 128K 兜底误判、频繁误触发自动压缩。

### 配置示例同步

`config.env.example` 的 `#ANTHROPIC_MODELS` 示例更新为新清单，供自定义模型清单的用户参考。
