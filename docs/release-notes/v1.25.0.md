## 功能：Claude 5.5（`claude-opus-5-5` / `claude-sonnet-5-5`）

Anthropic 于 2026-09-22 / 09-28 相继发布 Opus 5.5 与 Sonnet 5.5（官方模型总览 +
thinking 支持表核实），本版完成接入：

| 模型 | 定价（每百万 token） | 上下文 | 思考 |
| --- | --- | --- | --- |
| `claude-opus-5-5`（新默认） | $4 / $20 | 1M | **always-on，不可关闭** |
| `claude-sonnet-5-5` | $2 / $10 | 1M | 默认开，`disabled` 全档 400，不可关闭 |

- **内置清单**：两款新模型进入 `/model` 选择器，`claude-opus-5-5` 取代 `claude-opus-5`
  成为 Anthropic 默认；上代 `claude-opus-5` / `claude-sonnet-5` 转 legacy 保留
  （连同 `claude-fable-5` / `claude-opus-4-8`），已保存的 `model.json` 选择不受影响。
- **thinking 规则**：5.5 系 thinking always-on（官方支持表：opus-5-5 标 Always on、
  sonnet-5-5 的 `disabled` 全档 400）——`/model` 二级思考面板对这两款不再提供「关闭」，
  effort 四档 low/medium/high/max 照常可调；上代 opus-5 / sonnet-5 仍可关闭
  （有防误伤断言钉住，不被新前缀误伤）。
- **上下文窗口**：`ModelContextWindows` 增补两条 1M 条目，`/context` 用量分桶与
  自动压缩的水位计算不再落保守兜底。
- **视觉零改动**：`VisionModels` 的 `claude-` 前缀天然覆盖新 id。
- **验证**：TDD 先写失败测试（4 处以功能缺失方式变红），最小实现后全量
  `mvn -pl springai-code-tui -am test` 2386 例（含 inline-patch）无失败。
  **已知边界**：本机无 `ANTHROPIC_API_KEY`，新 id 的真机冒烟未做，待有 key 后可按
  `@EnabledIfEnvironmentVariable` 门控模式补一条。

## 功能：仓库根 `AGENTS.md`

新增 [AGENTS.md](../../AGENTS.md)：面向在本仓库工作的 AI 编码智能体（Claude Code、
Codex、code-tui 等）的浓缩版项目指令——构建测试命令（`-pl` + `-am` +
`surefire.failIfNoSpecifiedTests` 两硬约束、禁整仓 `mvn test`）、模块结构、代码/测试/
提交约定、spec→plan 流程、发布与安全要点。内容全部提炼自 `CONTRIBUTING.md`、
`ci.yml` 与根 `pom` 等既有事实，冲突时以 `CONTRIBUTING.md` 为准。

code-tui 自身启动时即加载 `<root>/AGENTS.md`（注入主/子 agent 系统提示），
这份文件同时是该项目指令功能在本仓库的自举示范。
