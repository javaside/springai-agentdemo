# springai-agentdemo v1.16.0

在 [v1.15.0](v1.15.0.md) 基础上的**功能版**（minor）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

本版聚焦两件事：一是让长时间跑任务时终端 tab 自己提示「需要你看一眼」；二是修复 glm-5.3 / 1M 窗口下手动 `/compact` 被 token 目标预算误挡住的问题，恢复「保留最近 20 个事件」的手动压缩语义。

**下载物仍是两个自包含运行包（解压即用，无需构建）：**

- `springai-code-tui-1.16.0-dist.tar.gz`（macOS / Linux 首选）
- `springai-code-tui-1.16.0-dist.zip`（Windows 首选）

两者内容一致：启动脚本（`bin/`）+ 主 jar + 全部运行期依赖（`lib/`）+ 配置示例 + 使用指南 + `LICENSE`/`NOTICE`/`README`。运行时界面版本标识为 **`v1.16.0`**。

> 完整功能全景与安全声明见 [v1.3.0 发布说明](v1.3.0.md) 与 [v1.0.0 发布说明](v1.0.0.md)；本文只列出相对 v1.15.0 的变化。

## 新功能：终端注意提示（tab 标题 + BEL）

此前 agent 跑完或弹出问询 / 权限审批 / 计划审批时，终端 tab 与普通 shell 没有区别；用户切去别的窗口工作，只能切回来才知道它已经等了很久。

本版把「需要你看一眼」写进终端自己的 UI：

- 问询 / 审批 / 计划审批开始等待用户时，tab 标题改为 `⏳ Code TUI 等待你的输入`，并发送一次 BEL。
- 回合完成时，tab 标题改为 `✓ Code TUI 已完成`，并发送一次 BEL。
- 用户按任意键或答完问询继续跑时，标题恢复为 `Spring AI Code TUI`。
- 用户主动 Esc 取消回合时不响「已完成」提示；他刚按过键，必然在场。
- 「已完成」标题保持到下一次按键，方便切回来时一眼看到状态。

实现上新增纯状态机 `AttentionTracker` 做边沿检测，避免 `drain` 每 33ms 重复响铃；`TerminalAttention` 通过 TamboUI backend 写 OSC 0/2 标题序列和 BEL，失败时静默降级，不影响主流程。

文档新增 [终端注意提示](../../springai-code-tui/docs/guide/reference.md#终端注意提示tab-标题--响铃) 小节，说明不同终端中的表现由用户终端配置决定。

## 修复：手动 `/compact` 不再误报「无可压缩内容」

v1.15.0 的手动压缩策略接入了基于上下文窗口的 token 目标预算。对 glm-5.3 这类 1M 窗口模型，手动目标预算会推到约 234k tokens；如果会话事件很多但估算 tokens 低于这个值，策略会在 `total <= targetBudget` 分支提前返回 `eventsRemoved=0`，UI 因而显示「无可压缩内容（历史尚短）」。

实际例子中，一个 470 事件、约 109k tokens 的会话就触发了这个误判：历史并不短，只是低于 1M 窗口推导出的手动 token 目标。

本版恢复手动 `/compact` 的事件窗口语义：

- 手动压缩启用 `MANUAL_MAX_EVENTS_TO_KEEP=20` 强制窗口。
- 当事件数超过 20 时，即使总 token 低于目标预算，也会归档旧事件并保留最近 20 个事件。
- 自动压缩不变，仍按 token 预算与校准策略工作。
- 切分时尽量回退到 root event 边界，避免从一组关联事件中间截断。

## 质量

发布前验证：

- `mvn -pl springai-code-tui test`
- `mvn -pl springai-code-tui -am clean package -Pdist`

本版新增回归网：

- **`AttentionTrackerTest`**：覆盖空闲、模态等待、忙转完成、DONE 保持、按键恢复、Esc 取消抑制、答完模态继续跑等边沿状态。
- **`TerminalAttentionTest`**：钉住 TamboUI 私有 backend 反射路径，验证 null runner 静默降级与 OSC 标题控制字符清理。
- **`CodeTuiViewAttentionTest`**：覆盖 view 层 drain 接线，确认模态入队、回合完成、Esc 取消分别落到正确状态。
- **`attention_smoke.py`**：真实 PTY 冒烟，断言完整回合后 OSC 0/2 标题含「已完成」且发出 BEL，按键后恢复默认标题，并覆盖 Esc 抑制路径。
- **`BoundedSummarizationCalibrationTest.forcedEventWindowCompactsEvenWhenTotalIsBelowTargetBudget`**：复现 470 事件低于 234k token 目标预算的场景，断言手动 `/compact` 仍移除 450 个事件并保留最近 20 个事件。

## 升级说明

无配置项变更、无依赖变更。`config.env` 可直接沿用。

终端注意提示使用标准 OSC 0/2 与 BEL；如果不希望听到声音或看到系统通知，可在终端自身设置里关闭响铃 / 通知。个别终端不支持标题写入时会自动降级，不影响对话和工具执行。
