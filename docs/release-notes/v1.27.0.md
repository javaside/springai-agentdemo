# v1.27.0 — 第四家搜索 DeepSeek 与 GPT-6.1 Sol / GPT-6 Luna

在 [v1.26.4](v1.26.4.md) 基础上的**功能版**（minor）。核心交付物仍是终端编码智能体 **`springai-code-tui`**。

发布日期：2026-10-22。

## 新增：DeepSeek 联网搜索（第四家搜索后端）

在博查、Brave、智谱三家之外接入 [DeepSeek Web Search API](https://api-docs.deepseek.com/zh-cn/guides/search)（`POST /v1/tools/search`），
与博查/智谱同为国内向源（查询词不出境），互为冗余——单一国内源额度耗尽时（实测博查 403）有了兜底。

- **工具名 `DeepSeekWebSearch`，只收一个 `query` 参数**：DeepSeek 的时间/域名/语言过滤没有独立请求参数，
  全靠搜索语法写进搜索词（`site:github.com`、`-site:zhihu.com`、`"精确短语"`、`-排除词`、`lang:zh,en`、
  `after:2025-01-01` / `before:2026`，可组合），语法教在工具描述里，无翻译层。
- **门控**：key 复用 `DEEPSEEK_API_KEY`（与模型同一把），配了即默认启用；不想为搜索按次计费可设
  `DEEPSEEK_SEARCH_ENABLED=0` 显式关（只认 0），不影响模型本身。`DEEPSEEK_SEARCH_COUNT`（默认 8，钳 [1,50]）
  只影响上下文占用，不影响单价。
- **计费**：5 元/千次成功请求（0.005 元/次），零结果与失败请求不计费。
- **真机实测回填**：200 响应字段与官方文档一致；但 `summary` 单条实测可达 2500+ 字符（文档宣称 600–800，
  内嵌 markdown 标题）——渲染已加 800 字符截断，否则默认 8 条一次搜索可吃掉上万 token 上下文。
- 系统提示指引段从三家（2³=8 态）扩为四家（2⁴=16 态）条目拼装，按注册状态渲染、绝不提不存在的工具；
  权限表登记为网络只读（NETWORK_READ），与三家同款。

设计文档见 `docs/superpowers/specs/2026-10-22-deepseek-web-search-design.md`（含真机实测形状与已知取舍）。

## 新增：OpenAI GPT-6.1 Sol 与 GPT-6 Luna 模型

GPT-6 家族从 lone `gpt-6-astra` 扩到三个在售成员，接入其中两个（官方模型页 2026-10-22 核实）：

- **`gpt-6.1-sol`**（2026-10-19 上线，官方现 Default 标签）：近 Astra 性能、$2/$10 一代五分之一价；
  1.05M 上下文 / 128K 输出；文本+图像输入；reasoning effort 五档 low..max，**不可关闭**
  （页面原文明说 none 与 minimal 均不支持，与 astra 同形状）。
- **`gpt-6-luna`**（2026-09-22 上线）：$0.1/$0.5 便宜快档，比 5.6-luna 更新一代；1.05M 上下文；
  文本+图像输入；effort 六档**含 none，可关闭**。
- 被取代的 `gpt-6-sol` 不接：与 6.1 同价且更旧，其模型页自指 6.1 为更新版。

五处同步点全部落位：Provider 模型清单与 effort 档位、`ModelContextWindows`（1,050,000，漏了会落 128K
保守兜底影响 /context 与自动压缩）、`VisionModels`（各自精确到具体 id，dated 快照放行，未核实成员
——含被淘汰的 gpt-6-sol——仍判不支持，防误伤测试钉住）、`config.env.example` 示例清单、视觉文档。

## 用户可见的变化

- 配了 `DEEPSEEK_API_KEY` 后模型多一个可用的联网搜索工具；系统提示按四家分工指引（中文国内走博查/智谱/
  DeepSeek，英文走 Brave）。
- `/model` 的 openai 家清单新增 `gpt-6.1-sol` 与 `gpt-6-luna`；两者的视觉输入、思考档位随官方规格生效。
- 未配相关 key 的用户无任何行为变化（工具不注册、模型清单不变）。

## 升级须知

- **默认启用 DeepSeek 搜索**：已有 `DEEPSEEK_API_KEY` 的用户升级后模型可自主选用搜索（按次计费），
  不想启用请设 `DEEPSEEK_SEARCH_ENABLED=0`。
- 发布包 `config.env.example` 新增 `DEEPSEEK_SEARCH_ENABLED` / `DEEPSEEK_SEARCH_COUNT` 两个条目，
  `OPENAI_MODELS` 示例行加入两个新模型 id。
