# v1.14.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare a complete local v1.14.0 release with consistent Maven versions, release documentation, verified self-contained archives, checksums, a release commit, and an annotated tag.

**Architecture:** Treat repository metadata, generated distribution artifacts, and Git release markers as three gated stages. Build once after the release notes draft, validate the exact resulting tar.gz/zip and derive test counts from Surefire XML, then write those immutable artifact hashes into the repository release notes without rebuilding; only after every check passes may the release commit and local annotated tag be created.

**Tech Stack:** Java 17, Maven 3.9+, Maven Assembly Plugin, Python 3 standard library (`pathlib`, `tarfile`, `zipfile`, `xml.etree.ElementTree`), Git

## Global Constraints

- Release version is exactly `1.14.0`; annotated tag is exactly `v1.14.0`.
- Baseline is `v1.13.0`; release notes describe only actual product behavior in `v1.13.0..HEAD`.
- Core artifacts are `springai-code-tui-1.14.0-dist.tar.gz` and `springai-code-tui-1.14.0-dist.zip`.
- Runtime remains JDK 17+ on macOS, Linux, and Windows.
- No third-party dependency is added.
- Full distribution build command includes `-am`: `mvn -pl springai-code-tui -am clean package -Pdist`.
- The release-note checksum placeholder is exactly `构建完成后写入最终校验值` and must not exist in the release commit.
- After final archive hashes are calculated, update repository release notes without rebuilding the archives.
- Do not push `main` or `v1.14.0`; do not create a GitHub Release or upload assets.
- Any version, test, build, archive, manifest, checksum, static, or tag check failure stops the release.
- Release commit and tag include no generated `target/` files.

## 新功能：LLM 流式空闲超时保护

全部六家 provider 的流式调用统一增加空闲超时：首个响应或任意两个响应数据块之间默认超过 300 秒无新数据时，当前调用会主动结束，不再无限停在「思考中」或工具运行状态。错误经现有回合收尾路径显示后，输入框恢复可提交。

超时复用 `CODETUI_LLM_READ_TIMEOUT_SECONDS`，合法范围仍为 10–3600 秒。上游已经给出明确超时错误时保留原始信息；本地检测到空闲时会提示实际等待秒数及配置名。超时前已收到的 usage 仍会在错误传播前提交，缓存命中统计不丢失。

---

## 改进：忙碌态继续显示缓存命中率

`THINKING` 与 `RUNNING_TOOL` 状态行现在继续显示当前会话累计的 `缓存命中 N%`，无需等待回到空闲态。忙碌态不重复显示上下文占比，以控制状态行长度；长工具摘要会先收缩，为缓存命中率、权限模式标签和 `Esc 取消` 让出空间。

---

## 改进：窄终端状态优先级与百分比高亮

空闲状态栏在空间不足时按「模型及动态状态 → `Enter 发送` → 次要帮助组」保留内容。`/model`、`Esc`、`Ctrl+C` 三项帮助会整组隐藏，非默认权限模式标签也计入宽度预算，避免上下文和缓存命中率再次被挤出 80 列终端。

`IDLE`、`THINKING`、`RUNNING_TOOL` 中仅缓存命中率的完整百分比值 `N%` 使用冷薄荷色加粗；`缓存命中` 标签、分隔符、上下文百分比和 `/context` 报告保持原样。

`mvn -pl springai-code-tui -am clean package -Pdist` → **构建完成后写入最终校验值**。本版新增流式首包/分片空闲超时、provider 装饰器接线、超时后会话恢复、上游错误保留、三态缓存命中样式及 80 列状态栏优先级回归测试。

- [ ] **Step 5: Replace quality and checksum placeholders from structured results**

Run this script once. It reads the same Surefire XML and final archive bytes already validated above, then replaces both fixed placeholder occurrences without manual transcription:

```bash
python3 - <<'PY'
from pathlib import Path
import hashlib
import xml.etree.ElementTree as ET
report_roots = [Path('springai-tamboui-inline-patch/target/surefire-reports'),
                Path('springai-code-tui/target/surefire-reports')]
tests = failures = errors = skipped = 0
for root in report_roots:
    for path in root.glob('TEST-*.xml'):
        node = ET.parse(path).getroot()
        tests += int(node.attrib.get('tests', 0))
        failures += int(node.attrib.get('failures', 0))
        errors += int(node.attrib.get('errors', 0))
        skipped += int(node.attrib.get('skipped', 0))
assert tests > 0 and failures == 0 and errors == 0
artifact_dir = Path('springai-code-tui/target')
names = ['springai-code-tui-1.14.0-dist.tar.gz', 'springai-code-tui-1.14.0-dist.zip']
digests = {name: hashlib.sha256((artifact_dir / name).read_bytes()).hexdigest() for name in names}
notes_path = Path('docs/release-notes/v1.14.0.md')
notes = notes_path.read_text()
quality = (f'`mvn -pl springai-code-tui -am clean package -Pdist` → **{tests} 个用例，'
           f'0 失败 0 错误**（其中 {skipped} 个需真实外部服务或 API Key 的 smoke 用例按条件跳过）。'
           '本版新增流式首包/分片空闲超时、provider 装饰器接线、超时后会话恢复、上游错误保留、'
           '三态缓存命中样式及 80 列状态栏优先级回归测试。')
checks = '\n'.join(f'{digests[name]}  {name}' for name in names)
checksum_section = (f'```text\n{checks}\n```\n\n```bash\n'
                    "shasum -a 256 -c <<'EOF'\n"
                    f'{checks}\nEOF\n```')
assert notes.count('构建完成后写入最终校验值') == 2
notes = notes.replace('`mvn -pl springai-code-tui -am clean package -Pdist` → **构建完成后写入最终校验值**。'
                      '本版新增流式首包/分片空闲超时、provider 装饰器接线、超时后会话恢复、上游错误保留、'
                      '三态缓存命中样式及 80 列状态栏优先级回归测试。', quality)
notes = notes.replace('构建完成后写入最终校验值', checksum_section)
assert '构建完成后写入最终校验值' not in notes
notes_path.write_text(notes)
print(f'updated release notes: tests={tests}, skipped={skipped}')
for name in names:
    print(digests[name], name)
PY
```
