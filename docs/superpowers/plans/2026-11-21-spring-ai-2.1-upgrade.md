# Spring AI 2.0.1 → 2.1.0 升级 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把仓库从 spring-ai 2.0.1 升到 2.1.0，六处版本联动同步完成，code-tui 全量测试与真机冒烟通过。

**Architecture:** 纯版本联动升级：先改 pom 六处并修编译，再以「预期红 → 校准 → 绿」的节奏处理行为断言，最后真机冒烟。无新功能代码；Java 源码改动预计集中在 AnthropicProvider（SDK 3.x）与钉行为测试。

**Tech Stack:** Java 17、Maven 3.9+、spring-ai 2.1.0（BOM）、spring-boot 4.2.0、agent-utils 0.14.0、官方 spring-ai-session。

**Spec:** `docs/superpowers/specs/2026-11-21-spring-ai-2.1-upgrade-design.md`

## Global Constraints

- 版本值逐一抄自 spec 联动矩阵：`spring-ai.version=2.1.0`、`spring-boot.version=4.2.0`、`openai-java-client-okhttp=4.101.0`、`anthropic-java-client-okhttp=3.8.0`、`spring-ai-agent-utils.version=0.14.0`、session 坐标 `org.springframework.ai:spring-ai-session` + `org.springframework.ai:spring-ai-session-advisor`（不写版本号，走 spring-ai-bom）。
- 语言级别锁 17；不改无关代码；注释写为什么。
- 测试命令必须带模块作用域：全量 `mvn -pl springai-code-tui -am clean test`；单类必须带 `-Dsurefire.failIfNoSpecifiedTests=false`。
- 升级后跑测试必须 `clean`（防旧 class 假失败）。
- 未改代码的打包一律 `-DskipTests`。
- 不在测试/文档/命令里出现任何明文 API key；真机冒烟走 `source ~/.secrets` 环境变量并 `@EnabledIfEnvironmentVariable` 门控。
- 预期 SEVERE/WARNING 的用例用 `dev.tamboui.testutil.ExpectedLog` 断言式接管，不裸静音。
- 提交信息 `type: 说明`（中文正文），一次提交只做一件事；功能与测试同提交。

## 升级类任务的 TDD 适配说明

本计划没有新功能测试可「先红」。等价纪律是：

1. **基线绿**：动 pom 前先跑代表性测试类记录通过基线；
2. **预期红**：升级后跑同批测试，出现的每一个红都必须能归因到 spec 事实表中的某一条
   （如「getText() null→""」）；归因不了的按真回归处理（修复代码或中止评估）；
3. **校准绿**：只改「钉旧行为」的断言/注释使其钉住 2.1.0 新契约，不许顺手放宽成
   模糊断言（如把 `assertEquals` 改成 `assertNotNull`）。

## Review Focus

1. **Anthropic Bearer 头被网关拒** → Task 5 真机冒烟必须覆盖 AnthropicProvider 实调。
2. **续跑/重试回放 reasoning_content 致上下文膨胀** → Task 5 DeepSeek 续跑冒烟 + Task 3 的
   `RetryingStreamChatModelTest` 全绿。
3. **partial `ToolCallPart` chunk 透传 UI** → Task 3 排红时检查所有模拟工具调用分片的 stub，
   partial 之后必须同 index 补发完整调用。
4. **社区 session 残留双胞** → Task 1 以 `dependency:tree` 断言无 `org.springaicommunity` 的
   session artifact。
5. **Boot 4.2 打挂 boot-demo** → Task 6 `mvn -DskipTests package` 对齐 CI 编译。
