# v1.9.1 发布设计

日期：2026-08-11

## 目标

发布 `springai-code-tui` v1.9.1 修订版，核心修复是 `/skill` 在技能数量较多时因面板高度失控而持续闪动、晃动并无法稳定选择。同步纳入 v1.9.0 之后已经合入 `main` 的下载运行入口与 Java 版本说明整理。

## 发布范围

- 父工程及所有子模块版本从 `1.9.0` 更新为 `1.9.1`。
- 新增 `docs/release-notes/v1.9.1.md`，说明：
  - 技能选择器改为最多显示 10 项的跟随窗口；
  - 所有技能仍可通过方向键遍历并确认；
  - README 与启动脚本的下载、运行和 JDK 17+ 说明整理。
- 在 `CHANGELOG.md` 顶部加入 v1.9.1 索引。
- 不新增依赖，不改变权限、模型调用或技能注入语义。

## 构建与验证

1. 运行 `mvn -pl springai-code-tui clean package -Pdist`，该命令执行模块测试并生成两个自包含归档。
2. 检查 tar.gz 与 zip：文件名为 `1.9.1`，根目录、主 jar、启动脚本、配置示例、指南、LICENSE 和 NOTICE 均存在。
3. 从归档主 jar 的 manifest 核对 `Implementation-Version: 1.9.1`。
4. 计算 SHA-256，写入发布说明后重新构建；若说明被打入归档导致校验变化，以最终归档为准。
5. 运行 `git diff --check` 并确认工作区只含发布准备改动。

## 发布流程

- 提交信息：`release: v1.9.1 发布准备`。
- 推送 `main`。
- 在发布准备提交上创建 annotated tag `v1.9.1` 并推送。
- 通过 `gh release create` 创建正式 Release，标题突出 `/skill` 大量技能选择器闪动修复。
- 上传：
  - `springai-code-tui-1.9.1-dist.tar.gz`
  - `springai-code-tui-1.9.1-dist.zip`
- Release 正文取自 `docs/release-notes/v1.9.1.md`，发布时将仓库内相对链接转换为绝对链接。

## 失败处理

任何测试、构建、归档检查、校验和或上传失败都会停止后续步骤；在产物验证完成前不创建 tag，在 GitHub Release 资产上传完整前不宣称发布完成。
