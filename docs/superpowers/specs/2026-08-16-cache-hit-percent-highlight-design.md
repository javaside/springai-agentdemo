# 缓存命中率百分比高亮设计

**日期**：2026-08-16
**范围**：`springai-code-tui` 状态栏样式

## 目标

让状态栏缓存命中率中的百分比值更容易扫读。例如 `缓存命中 78%` 中仅 `78%` 使用薄荷色加粗，标签和分隔符保持当前状态栏样式。

## 设计

### 展示范围

高亮应用于当前会显示缓存命中率的三种普通状态：

- `IDLE`
- `THINKING`
- `RUNNING_TOOL`

只高亮完整百分比值（数字和 `%`），不高亮 `缓存命中` 标签。无缓存命中率时保持现有行为，不渲染对应片段。

会话压缩、选择器、审批和等待子任务收尾等专用状态行保持现状。`/context` 多行报告不在本次范围内。

### 样式

在集中调色板 `Theme` 中增加缓存命中率数值样式，使用与欢迎横幅模型名一致的冷薄荷色 `Color.indexed(115)` 并加粗。该颜色用于强调数据，不表达运行中、成功或警告语义。

### 渲染与宽度

状态栏现有字符串继续作为内容组装和终端显示宽度计算的依据。最终构造 `Text` 时，将匹配到的 `缓存命中 N%` 拆成普通文本 Span 和高亮数值 Span。

拆分应作用于状态栏最终文本或等价的统一渲染入口，使 `IDLE`、`THINKING` 和 `RUNNING_TOOL` 使用同一套规则，避免三处分支分别拼接样式。

ANSI 样式不进入字符串，也不参与 `displayWidth(...)`。现有空闲态信息优先级、忙碌态后缀顺序和工具摘要收缩逻辑均不改变，因此 80 列终端下的可见性行为保持不变。

## 测试

增加或扩展状态栏离屏渲染测试，覆盖：

1. `IDLE` 中只有 `N%` 使用薄荷色加粗，`缓存命中` 标签保持 `HINT`。
2. `THINKING` 中只有 `N%` 使用薄荷色加粗，其他静态后缀保持原样。
3. `RUNNING_TOOL` 中只有 `N%` 使用薄荷色加粗，工具运行样式和暗色后缀保持原样。
4. 无缓存统计时不产生高亮 Span 或悬空分隔符。
5. 80 列终端下 `缓存命中 N%` 仍完整可见，现有宽度优先级不回归。

## 非目标

- 不改变缓存命中率计算、采集、刷新频率或文案。
- 不按命中率高低切换颜色。
- 不高亮上下文占比或其他状态栏数字。
- 不修改 `/context` 报告样式。
