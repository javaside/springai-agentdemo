# 操作键、斜杠命令与已知限制

> 快速参考页：按键、斜杠命令与已知限制（更早版本对应的 README 三节已并入本页）。


| 按键 | 行为 |
| --- | --- |
| Enter | 发送输入框中的消息；**回合进行中按下则是「插话」**——不打断回合，随下一次模型调用送达（见「回合中插话」）。要排到下回合用 `/queue` |
| `\` + Enter | 在输入框内换行（终端无关） |
| ↑ / ↓ | 回溯 / 前进已提交的历史消息（多行时先在行内移动光标） |
| Ctrl+A / Ctrl+E | 光标跳到行首 / 行尾 |
| Ctrl+← / Alt+← / Alt+B | 光标向左按词跳（中文按单字跳） |
| Ctrl+→ / Alt+→ / Alt+F | 光标向右按词跳（中文按单字跳） |
| Ctrl+W / Alt+Backspace | 删除光标前一个词（空白为界；中文按单字删） |
| Ctrl+U / Ctrl+K | 删到行首 / 删到行尾（以当前逻辑行为界，不跨行） |
| Ctrl+X | 取消本次输入识别出的图片附件（见「视觉输入」；某些全局热键会抢占按键，撞上时按了没反应） |
| Shift+Tab | 循环权限模式（默认 → 自动接受编辑 → 计划模式 → 跳过权限检查 → 默认；当前档位常驻状态栏） |
| Esc | 取消当前正在进行的回合（工具调用/模型生成）**；后台任务不受影响**，要停它去 `/tasks` 按 `k`；审批面板打开时 = 拒绝并中断本回合。**尚未处理完的插话会被放回输入框**（不丢弃——按 Esc 通常正是「别跑了，听我的」，那句话该还给你） |
| Ctrl+C | 退出程序 |

审批面板打开时：↑↓ 选择、`1`-`5` 快选（只移动高亮，仍需 Enter 确认）、Enter 确认、Esc 中断。

计划审批面板（计划模式下模型调 `ExitPlanMode` 时弹出，计划正文打进上方滚动区、面板只放选项）：↑↓ 选择、`1`-`3` 快选（同样只移动高亮）、Enter 确认、Esc 中断本回合。选第 3 项「继续完善计划」会进入一行反馈输入：打字后 Enter 提交（可留空），Esc 退回选项。


## 终端注意提示（tab 标题 + 响铃）

切去别的窗口干活时，agent 的状态直接写在**终端自己的 UI** 上，不用切回来看：

| 时刻 | tab 标题 | 响铃 |
| --- | --- | --- |
| 问询 / 审批 / 计划审批开始等待你 | `⏳ Code TUI 等待你的输入` | 响一声（终端会在 tab 上标记） |
| 回合完成（任务做完） | `✓ Code TUI 已完成` | 响一声 |
| 你按任意键 / 答完继续跑 | 恢复默认标题 | — |

细节：

- **macOS Terminal.app / iTerm2 收到 BEL 会在 tab 上标记**（Terminal.app 默认画一个点，可在设置里改成弹通知）；tmux 同样支持。写进 tab 标题的内容只出现在终端壳上，不占对话区一行。
- **你主动 Esc 取消的回合不响**「已完成」——你刚按过键，必然在场，再响是打扰。
- **答完问询、活继续跑**时不响（答完就响「完成了」是撒谎），只把标题恢复默认。
- **「已完成」标题保持**到你下一次按键：切回来一眼可见，按任意键即恢复默认。
- 响铃的**表现形式由终端配置决定**（点标记 / 通知 / 声音），应用只发标准 BEL；不想要可在终端设置里关。写标题走 OSC 0/2 标准序列，个别终端不支持也不影响其他功能。


## 斜杠命令

输入 `/` 会弹出命令补全菜单（↑↓ 选择、Tab 补全、Enter 运行、Esc 关闭）：

| 命令 | 行为 |
| --- | --- |
| `/model` | 打开模型选择器，在当前 provider 的模型间切换（选中即记住，下次启动自动恢复） |
| `/compact` | 手动压缩会话历史 |
| `/clear` | 清空当前上下文、开一个全新空会话（旧会话留盘，可 `-c` 恢复）；同时清屏并复位面板、**终止全部后台任务**（新会话不该有旧会话的任务还在烧钱） |
| `/context` | 查看上下文用量：事件数分桶、上下文占用（系统提示词 + 会话消息）与构成占比、缓存命中率、视觉图片、自动压缩阈值（详见发版说明 v1.18.0） |
| `/skill` | 为本条消息指定技能 |
| `/skills` | 查看可用技能清单（模型按需自动调用） |
| `/reload` | 重扫技能目录 + 重载 MCP 配置（`SKILL.md` 与 `mcp.json` 改动即时生效，无需重启；MCP 部分仅空闲时执行，忙碌时跳过并提示） |
| `/mcp` | 管理 MCP 服务器：列出全部（含禁用/失败项），Enter 启用/禁用（即时生效 + 回写 `mcp.json`），`r` 重载配置文件（diff：新增/移除/参数变更即时生效，未变不闪断），Tab 展开工具清单（仅空闲时可用） |
| `/permissions` | 打开权限规则面板：↑↓ 选择、`d` 删除（先确认）、Esc 关闭；当前模式与内置底线摘要仍打进对话区。**新增**规则走审批面板的「允许，永久」 |
| `/hooks` | 打开生命周期钩子面板（任何时候可开）：按事件分组列出全部钩子（命令 / matcher / 超时 / 来源，项目层未信任条目带 ⚠ 标记），`t` 信任项目层（写 `~/.codetui/hooks-trust.json`，即时生效）、Esc 关闭。配置格式见下方「生命周期钩子」 |
| `/init` | 让 agent 分析当前项目并生成/改进**项目级 `AGENTS.md`**（目标固定为工作目录下的 `AGENTS.md`，不碰用户级 `~/.codetui/AGENTS.md`）：只写「从代码推不出来的事实」（构建/测试命令、关键约定、注意事项）；已存在时先通读、在既有内容基础上改进而非整篇重写。`AGENTS.md` 在启动时一次性加载，**重启 code-tui 后生效**；agent 忙时排队（同 `/continue`） |
| `/review` | 让 agent **只读审查**当前工作树的改动（先 `git diff HEAD` 与 `git status` 了解全貌，不动手修改）：从正确性 / 安全 / 测试 / 可维护性四个维度找问题，按严重程度从高到低输出，每条给出文件:行号、问题描述、为什么要紧、建议修法，没有问题的维度不硬凑；未跟踪的新文件也会读来看（同样不改）。非 git 目录直接提示拒绝（不白烧一回合）；agent 忙时排队 |
| `/resume` | 打开历史会话面板：↑↓ 浏览（id 前缀 + 本地时间 + 首条用户消息摘要，摘要后台逐条补齐、面板秒开），Enter 恢复选中会话、`f` 分叉选中项、`d` 两段式删除（当前会话不可删）、Esc 关闭 |
| `/diff` | **不经模型**即时查看工作树改动（只读，忙时可看）：后台线程跑 `git diff HEAD`（staged 与 unstaged 合一）逐字打进滚动区——`+` 行绿、`-` 行红、其余默认色；未跟踪文件只列名字 + 字节数；工作树干净时一行提示。**Esc 不取消**（git 亚秒级，不值得做进程取消）；生成期间连按只提示「正在生成 diff…」不重复执行；`/clear` 或切换会话后没打完的部分直接作废（不串进新画面） |
| `/fork` | 分叉当前会话：历史复制到新会话并切换过去接着聊，原会话原样保留（可随时 `/resume` 回去）；当前会话为空时提示不分叉 |
| `/tasks` | 打开后台任务面板：↑↓ 选择、Enter 展开结果、`k` 终止运行中的任务（先确认）、Esc 关闭（任何时候可开，不要求空闲） |
| `/goal <条件>` | 设定目标循环：agent 跨轮自主推进，每轮结束由独立小模型评估是否达成，未达成则带着结论继续；配轮数 / 无进展 / token 预算三重熔断（均为暂停语义，发消息恢复）。评估器与各阈值由 `CODETUI_GOAL_*` 环境变量配置（清单见 `bin/config.env.example`） |
| `/goal` | 打开目标状态面板：条件、状态（RUNNING/PAUSED(原因)/终态）、轮次 N/M、token 用量、stalled 连击、最近 8 条评估轨迹与运行时长；终态后报告保留至下一个 `/goal` 命令 |
| `/goal stop`（别名 `clear`） | 清除当前目标并回显被清条件；goal 只活在进程内存态，`-c` 恢复会话时旧目标已失效（有提示行） |
| `/continue` | 续跑上次未完成的计划；同时把**正在跑**、以及**已完成待取回**的后台任务告诉模型，免得同一批活跑两遍（见 [background-agent.md](background-agent.md)） |
| `/queue <消息>` | 把消息排到**下一回合**再发，而不是插进当前回合（回合进行中直接 Enter 是「插话」，见 [interjection.md](interjection.md)）。空闲时等价于直接发送 |
| `/help` | 显示可用命令与快捷键 |
| `/exit` | 退出程序 |


## 启动参数

| 参数 | 行为 |
| --- | --- |
| `-c` / `--continue` | 恢复**最近一次**会话（按会话文件最后修改时间选取） |
| `--resume <会话id前缀>` | 恢复指定历史会话：前缀唯一匹配即可（会话 id 形如 `20260412T093015-1a2b3c`，可在 `/resume` 面板查看；精确命中优先于前缀匹配）；与 `-c` / `--continue` **互斥**（同给直接报错退出）；匹配不到或有歧义（多个会话同前缀）时列出候选后退出 |
| `-p <提示词>` | 非交互模式：跑一个回合后退出，**stdout 只输出最终回复**（进度与工具调用走 stderr）；`-p -` 表示提示词从 stdin 整段读入。权限请求一律 fail-closed 拒绝（可用 `--permission-mode` 或 allow 规则放宽），模型发起问询则取消回合并以退出码 2 结束；退出码 0=正常（含提交计划）/ 1=失败。会话照常落盘，可配 `--resume` 链式多步 |
| `--output-last-message <文件>` | 配合 `-p`：最终回复在打印到 stdout 的同时写入该文件（写入失败仅 stderr 告警，不改退出码）；缺路径参数时忽略并告警 |

权限相关的启动参数（`--permission-mode`、`--dangerously-skip-permissions`）见 [permissions.md](permissions.md#启动参数)。


## 生命周期钩子（hooks）

在固定生命周期时点自动执行你配置的 shell 命令。四个事件：

| 事件 | 触发时机 | 退出码语义 |
| --- | --- | --- |
| `PreToolUse` | 工具执行前（权限已放行后） | `exit 2` = **拦截**本次调用，stderr（截 2000 字）作为理由返回给模型；`exit 0` = 放行（stdout 丢弃）；其它非零 / 超时 / 启动失败 = 不拦截，仅记日志 |
| `PostToolUse` | 工具执行成功后 | `exit 0` 且 stdout 非空 → stdout（截 2000 字）以 `[PostToolUse 钩子输出]` 段追加进工具结果（UI 与模型都可见）；非零 → 不追加任何内容，UI 一行提示 |
| `Stop` | 回合结束时 | 通知型：输出忽略，非零的 stderr 首行进通告通道；**异步执行**，不阻塞回合收尾 |
| `SessionStart` | 启动装配时 | 通知型：同上；**同步执行**，慢钩子会拖慢首屏（通知型建议配短 timeout） |

### hooks.json 格式

配置文件两层：`~/.codetui/hooks.json`（用户层）与 `<工作目录>/.codetui/hooks.json`（项目层），
同事件**合并全部执行**（用户层在前）。文件缺失、JSON 非法或某条目缺字段只跳过该文件/该条并记 WARN，
不影响其余钩子。

```json
{
  "hooks": {
    "PreToolUse":   [ { "matcher": "Bash|Write", "command": "./ci/guard.sh", "timeout": 30 } ],
    "PostToolUse":  [ { "matcher": "Write|Edit", "command": "npx prettier --check" } ],
    "Stop":         [ { "command": "notify-send done" } ],
    "SessionStart": [ { "command": "./scripts/env-check.sh" } ]
  }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `command` | 是 | 缺失该条跳过（WARN）。经 `sh -c` 执行，工作目录为项目根 |
| `matcher` | 否 | **工具名正则（整段匹配）**，如 `Bash\|Write`；省略或空 = 全部工具。仅对 Pre/Post 有意义，Stop/SessionStart 恒匹配（写了也忽略）。**对 MCP 工具无效**：MCP 工具不触发钩子，matcher 写 `mcp__` 前缀永远等不到 |
| `timeout` | 否 | 秒数；默认 60，有效范围 [1,120]——小于 1 回退默认 60，大于 120 截到 120。上界刻意远小于流式空闲超时默认 300s |

未知事件键跳过（WARN）；未知字段忽略（向前兼容）。**没有热重载**：改 hooks.json 需重启生效。

### stdin payload

钩子进程的 stdin 收到一行 UTF-8 JSON（工具入参以原始 JSON 串形式内嵌）：

```json
{"event":"PreToolUse","toolName":"Bash","toolInput":"{\"command\":\"ls\"}","sessionId":"20261025T093015-1a2b3c","turnId":3,"taskId":"","root":"/path/to/project"}
```

| 字段 | 出现于 | 空值行为 |
| --- | --- | --- |
| `event` | 全部事件 | 恒有，值为事件名（同配置键） |
| `toolName` | 仅 Pre/Post | Stop/SessionStart **不发**该字段（而非发空串） |
| `toolInput` | 仅 Pre/Post | 原始入参 JSON 串，超长截 8KB；Stop/SessionStart 不发 |
| `toolOutput` | 仅 Post | 工具输出，超长截 8KB |
| `sessionId` | 全部事件 | 无值时发 `""`（空串，非 null） |
| `turnId` | 全部事件 | 无归属回合（Stop/SessionStart、后台任务）时为 `-1` |
| `taskId` | 全部事件 | 无值时发 `""`（空串，非 null）；子 agent / 后台任务调用时是任务 id |
| `root` | 全部事件 | 项目根绝对路径（即钩子进程的工作目录） |

子 agent 与后台任务的工具调用同样触发 Pre/Post——引擎不按来源筛选，钩子要区分来源时读
`taskId` / `turnId` 自行判断。

### 项目层信任

hooks 能执行任意命令，而项目层 hooks.json 随仓库分发——clone 别人仓库不该自动执行其中的命令。因此：

- 项目层钩子默认**不执行**（四个事件全部），启动时通告一行「⚠ 项目层 hooks.json 未信任」。
- `/hooks` 面板查看全部钩子（未信任的项目层条目也列出并标记），按 `t` 信任：把当前文件内容的
  sha256 记入 `~/.codetui/hooks-trust.json`（用户空间、按项目根绝对路径），**即时生效**。
- 文件内容任何变更都会使记录失配——下次启动回到未信任，需重新 `t`；面板对 mtime 晚于信任时刻的
  文件标 ⚠ 提示复查。用户层钩子（你自己写的）无需信任。

残余风险（已声明接受）：hash 信任只防「信任后被改」，防不住 agent 自写信任文件（本工具无沙箱是既有
立场，真修需要进程外信任锚，超出本项目范围）。headless（`-p`）无面板：在同仓库开一次 TUI 执行
`/hooks` + `t` 后信任持久生效；`--dangerously-skip-permissions` 不旁路钩子信任。MCP 工具（`mcp__`
前缀）不触发钩子——黑名单场景对 MCP 价值低（权限层已对未知工具兜底询问/拒绝），列为本期非目标。


## 已知限制

- **滚动区不可翻页**：对话滚动区依赖终端自身的 scrollback，程序内不支持翻页控件（输入框 ↑↓ 回溯的是「已提交的历史消息」，与滚动区翻页无关；历史仅内存态，退出不保留）。
- **宽字符光标对齐**：输入框光标位置按显示宽度（东亚宽字符计 2 列）对齐，但极端的 grapheme 组合（如某些 emoji ZWJ 序列、组合字符）可能出现轻微偏移。
- **部分 Ctrl 组合键不可绑定**：终端把 `Ctrl+A..Z` 发成控制字节 1~26，其中 `Ctrl+H/I/J/M` 与 Backspace/Tab/Enter 字节相同、无法区分，故编辑快捷键避开了这几个字母；`Shift/Alt+Enter` 换行能否生效取决于终端能否区分修饰键（Apple Terminal 等区分不了），可靠换行请用 `\` + Enter。
- **无工具沙箱**：见 [security.md](security.md)——权限层是**执行前的人工确认**，不是边界强制；批准之后所有工具（含文件系统工具）仍不受 root 约束。自写的真沙箱（`SandboxedShellTool` 等校验所有工具路径参数）列为后续增强项，本版本未实现。
- **权限层本期未做的**：
  - **规则只能删不能改**：`/permissions` 是交互面板，可以 `d` **删**规则（删前要确认；删 deny 时提示会明说「这会放宽权限」）。**新增**仍走审批面板的「允许，永久」——面板内手输 DSL 需要校验与错误提示，不在本期。要改一条规则，先删再重新授权，或直接编辑 `permissions.json`。
  - **无工具自审接缝的实现方**：判定顺序第 3 步（工具自己声明本次调用的危险度）是预留插槽，本期没有工具实现它。
  - **规则不区分子 agent**：主 agent 与子 agent 共用同一套规则与模式，不能只给某类子 agent 更严的权限。
  - **审批面板逐个排队**：多个子 agent 并发触发审批时面板一个一个弹（队列上限 8 条），不能批量处理。
  - **计划模式下子 agent 只能做只读调查**：它与主 agent 共用同一个引擎，故写操作照样被 DENY。它会收到一段**专属的**系统提示（说明自己处于只读调查阶段、把发现报告回主 agent 就是交付），但**没有 `ExitPlanMode`**——提交计划是主 agent 的事。所以计划模式下派子 agent 去调查是正常用法，派它去做会落盘的事则做不成。
    > 子 agent 的提示段刻意**不与主 agent 版统一**：主 agent 版结尾指向 `ExitPlanMode`，而子 agent 的工具集里根本没有这个工具，照抄等于指一条走不通的路——把「不知道为什么被拒」换成「知道了、照做了、还是失败」，比不给提示更糟。
- **历史会话的浏览/切换已支持**（本条曾长期是限制，`/resume` 与 `/fork` 已落地）：`/resume` 面板可浏览、恢复、分叉、删除历史会话，`/fork` 分叉当前会话（原会话保留），见「斜杠命令」表；精确恢复指定历史会话用启动参数 `--resume`（见「启动参数」）。会话仍按项目隔离，面板与 `--resume` 只见当前项目目录下的会话。
- **后台任务不跨进程**：后台子 agent 只活在当前进程里（注册表是内存态，不落盘）。退出或 `/clear` 会终止全部后台任务，重启后 `TaskOutput` 拿旧 id 只会得到「未知任务」。`-c` 恢复的是会话历史，不是在跑的任务。
- **长期记忆无「自动整理」**：跨会话长期记忆已具备（AutoMemoryTools），但暂未接入定期 consolidation（自动汇总/去重冗余记忆）触发器；记忆的增删改全由模型按需驱动。
- **视觉输入的边界**（详见 [vision.md](vision.md)）：**终端里显示不了图片**（只会看到一行文件路径）；**`Bash` 生成的图片文件不会自动产生引用**（有意为之，模型想看就 `Read` 它）；**不支持 `Ctrl+V` 直接粘剪贴板里的图**（贴图靠写路径/拖文件）；**裸路径自动识别必然有误附**（附件行可见 + `Ctrl+X` 撤销兜底，不靠规则消灭）；**取消键可能被 OS 级全局热键抢走**（已知：Chrome 的 Gemini 扩展抢 `Ctrl+G`，故取消键已从 `Ctrl+G` 改为 `Ctrl+X`；这类冲突在代码里修不了，只能换键，而换给谁都有被抢的可能）；**视频恒不投递**。另外，消息序列在 DeepSeek 视觉模型与智谱视觉模型上已真机验证过（见 CHANGELOG v1.17.0 / v1.19.0）；`api.openai.com` 原生端点与 Anthropic / 千问仍未真机验证，第一次真用仍可能 400。
- **MCP 传输：stdio + Streamable HTTP，管理粒度为整 server**：本地子进程走 stdio（默认），远程 server 走 Streamable HTTP（`type: "http"`，详见 [mcp.md](mcp.md)）；旧标准 `"sse"`（官方已 deprecated）暂未支持，配了会记 WARN 并跳过。`/mcp` 可运行期启用/禁用 server（即时生效 + 回写 `enabled`）；改 `mcp.json`（新增/删除条目、改 `command`/`args` 等）经 `/reload` 或面板 `r` 键重载即时生效，**无需重启**；管理粒度为整个 server，不细到单个工具。工具名未做长度截断与跨 server 碰撞去重——默认 DeepSeek 无 64 字符上限、实测工具名远短于此且碰撞需刻意构造，故本期可接受。**退出清理为「有界优先」**：`/exit` 时关闭子进程硬限 2s，若某 server 恰在 2s 内未优雅关完，进程会被 JVM 退出带走、可能短暂残留由 OS 回收——这是「不卡退出」优先于「保证优雅清理」的有意取舍。
